1. PROJECT OVERVIEW & REPOSITORY
--------------------------------------------------------------------------------
- Goal: Build an enhanced MSX2+ / MSX-DOS 2 graphical and musical port of the
  1980 RPG "The Wizard's Castle" (based on Daniel D. Miller's C++ port in
  `winwiz/` and Joseph R. Power's 1980 BASIC original), using the `MSXgl`
  library (`MSXgl/`).
- Public GitHub Repository: https://github.com/wilsonpilon/wizcastle
- Git Remote (SSH alias):   git@github-pessoal:wilsonpilon/wizcastle.git
- Licensing: Dual CC BY-SA 4.0 (combined work with MSXgl) + MIT (standalone C
  code in `MSXgl/projects/wizcastle/` and docs in `docs/`). See `LICENSE`.

2. VERSIONING SCHEME (X.Y) & RELEASE POLICY
--------------------------------------------------------------------------------
- `X` (Major): Increments on each completed feature milestone, new specification,
  or start of a new implementation phase (e.g., Phase 1 = 1.x, Phase 2 = 2.x).
- `Y` (Minor): Increments on EVERY compilation/build (`.\build.bat`), no matter
  how small the change is.
- Version header: `MSXgl/projects/wizcastle/src/wiz_version.h`
- History log:    `CHANGELOG.md` (must be updated on every build).
- Tracked binaries: Both `MSXgl/projects/wizcastle/out/wizcastle.com` and
  `MSXgl/projects/wizcastle/emul/dsk/DOS2_wizcastle.dsk` are tracked in Git.
- Releases: Published periodically on GitHub (e.g. `v1.1`, `v1.6`) with a
  dedicated subtitle consolidating all intermediate changes since the previous
  release.

4. CRITICAL TECHNICAL FINDINGS & GOTCHAS (READ BEFORE CODING!)
--------------------------------------------------------------------------------
1) Rebuilding MSXgl Engine Modules (`CompileSkipOld = true`):
   Whenever `msxgl_config.h` is modified, you MUST delete cached `.rel` files
   and `msxgl.lib` before running `.\build.bat`:
   `Remove-Item MSXgl\projects\wizcastle\out\*.rel, MSXgl\projects\wizcastle\out\msxgl.lib -Force`
2) `SCREEN 12` + `MSXgl` `Print` Module:
   `VDP_SetMode(VDP_MODE_SCREEN12)` sets `g_VDP_Data.Mode = 12`, which is not
   handled by `Print_SetMode()` in `MSXgl/engine/src/print.c` (only
   `VDP_MODE_GRAPHIC7` = 8 is handled). Always set:
   `g_VDP_Data.Mode = VDP_MODE_GRAPHIC7;`
   immediately after `VDP_SetMode(VDP_MODE_SCREEN12)` before calling
   `Print_SetBitmapFont()`. In `SCREEN 12` YJK mode, `0xF8` is pure white and
   `0x00` is pure black.
3) `TMS9918A` (MSX1) Register Mirroring:
   Because `vdp.c` is compiled with `MSX_VERSION=MSX_2P`, calling `VDP_SetMode`
   or `VDP_WriteVRAM_16K` writes to `R#8..R#25`. On a `TMS9918A`, register
   numbers are masked to 3 bits (`reg & 7`), overwriting `R#0..R#7`! Always use
   `TMS_RegWrite`, `TMS_FillVRAM`, and `TMS_WriteVRAM` on MSX1.
4) `RDSLT` Interrupt State & VBlank Timing:
   BIOS `RDSLT` (`000Ch`) disables interrupts (`DI`) and does not re-enable
   them. Always call `EnableInterrupt()` after slot reads, and use V9958 `S#2`
   bit 6 (`VR`) polling in `WaitFrames()`.
5) `g_Font_MGL_Sample6` Offset:
   Has a 4-byte header (`0x88, 0x68, 0x00, 0xBF`) followed by ASCII `0..191`.
   ASCII `32` (`' '`) is at `g_Font_MGL_Sample6 + 4 + (32 * 8)` (offset 260).
6) MSX-DOS 2 `BDOS` (`0005h`) + Memory Mapper Page 2 (`0x8000–0xBFFF`):
   Never pass a buffer at `0x8000–0xBFFF` directly to `BDOS 48h` (`_READ`)
   while a custom Mapper segment is paged into Page 2, because MSX-DOS 2
   switches segments internally during disk I/O and writes into the default TPA
   Page 2 segment! Always read into a buffer in Page 1 TPA (`g_DiskBuf[2048]`
   in `.bss`, below `0x8000`) with `g_OrigSegPage2` mapped, preserve `IX`
   (`push ix` / `pop ix` around `call 0x0005`), then call
   `DOSMapper_SetPage2(seg)` and `Mem_Copy(g_DiskBuf, 0x8000 + off, 2048)`.
   And always call `Wiz_MapperCleanup()` before returning to MSX-DOS 2 so all
   allocated user segments are freed cleanly (`DOSMapper_Free`).
